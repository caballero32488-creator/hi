# TinyMacro
Android (Kotlin/Compose) macro recorder + player with floating overlay; iOS in-app module (see ios/).
Open the project root in Android Studio (Koala+), sync Gradle, run on a device (API 26+).
1. Home → grant overlay permission, enable "TinyMacro Gestures" in Accessibility, tap Show overlay.
2. Open any app → ⏺ to record (gestures are captured, then re-injected), ⏹ to stop (auto-saves).
3. ▶ to replay; edit/reorder/delete steps in Recorder; manage in My Macros.
